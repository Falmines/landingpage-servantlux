## Isi
- index.html
- style.css
- script.js
- servantlux-logo.png

## Cara menjalankan
1. Simpan semua file dalam satu folder.
2. Buka `index.html` di browser.
3. Untuk development, bisa menggunakan VS Code + Live Server.

## Interaksi
- Menu mobile responsive
- Smooth scrolling
- Scroll reveal animation
- Animated impact counters
- Popup/modal About Us
- Popup detail setiap Activity
- Popup Donate Now
- Popup Join Volunteer
- Popup Contact
- Tutup popup dengan tombol X, klik area luar, atau tombol ESC.
